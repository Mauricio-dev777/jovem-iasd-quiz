# Quiz Jovem IASD

Sistema de quiz em tempo real desenvolvido para eventos do grupo de jovens da Igreja Adventista do Sétimo Dia.

Os participantes acessam o quiz pelo celular, enquanto o apresentador controla toda a dinâmica pelo computador. As perguntas, respostas e ranking são sincronizados em tempo real utilizando WebSockets.

---

## Funcionalidades

- Login do apresentador
- Entrada dos participantes pelo celular
- Tela de espera (Stand By)
- Controle do quiz em tempo real
- Perguntas configuráveis
- Revelação da resposta correta
- Ranking em tempo real
- Sistema de pontuação
- QR Code para acesso rápido
- Comunicação utilizando Socket.IO

## Como executar

Clone o projeto:

```bash
git clone https://github.com/SEU-USUARIO/Quiz-Jovem-IASD.git
```

Entre na pasta:

```bash
cd Quiz-Jovem-IASD
```

Instale as dependências:

```bash
npm install
```

Execute o servidor:

```bash
npm start
```

Acesse:

```
http://localhost:3000
```
